# Starter files

Empty copies of the four files the dashboard uses. Step 2 of the setup guide has Cowork create them for you
in `OneDrive › Documents › Cowork › COS Comms Dashboard`; use these only if you'd rather upload them yourself.

- `comms-feed.json`: written by your automations.
- `teams-sweep.json`: the Teams sweep's marker. Set `lastSweepAt` to the current time before the first sweep.
- `my-tasks.json` and `dashboard-state.json`: written by the dashboard (it creates them if they're missing).

The format is described in [`docs/feed-format.md`](../docs/feed-format.md).
